Encil is an advanced, offline-first Android application designed specifically for the precise management of pledges and pawned assets. Engineered for security and convenience, it operates completely offline, ensuring that sensitive financial data remains solely on your device.

At its core, the application provides an intuitive interface for creating and monitoring pawn entries. Users can record principal amounts, monthly interest rates, and detailed item descriptions. A notable feature is the auto-synchronization between pledge dates and transferee dates, which ensures backdated entries are accurately maintained. Additionally, the app includes smart auto-suggestions for recurring fields like addresses and names, preventing redundant typing and improving workflow speed.

Security is a paramount feature of Encil. The application offers a multi-layered protection system including a primary password and a secure PIN lock. For supported devices, users can leverage biometric authentication to access the main dashboard swiftly. The locking mechanism is fully customizable, allowing users to enable or disable PIN requirements based on their preference without the risk of losing previously saved credentials.

For data analysis and reporting, Encil features a comprehensive statistics screen. This section now includes a dedicated transferee analysis mode, which provides detailed breakdowns of active and closed pledges for individual transferees. Furthermore, the export module allows for the generation of reports in Excel, PDF, or JSON formats, with the new capability to export data for entire calendar years, streamlining financial audits.
